# รวมคำพยานชีวิต "พระเจ้ามีจริงและช่วยคุณได้"
### คริสตจักรนิวไวน์ อุดรธานี (New Wine Church Udonthani)

เว็บไซต์รวบรวมเรื่องราวชีวิตจริง 24 คำพยาน จากผู้ที่ได้รับการช่วยเหลือ การรักษาโรคร้าย การกู้ชีวิต และการอวยพรในหน้าที่การงานและการเงินอย่างอัศจรรย์โดยพระเยซูคริสต์

---

## 🌟 จุดเด่นของเว็บไซต์
1. **CI ตรงตามอัตลักษณ์คริสตจักรนิวไวน์อุดรธานี:**
   - โทนสีแดงนิวไวน์ (`#D6001C`) และทองสง่างาม
   - สัญลักษณ์เปลวไฟพระวิญญาณบริสุทธิ์สีขาว
   - ตัวอักษรฟอนต์ **Noto Sans Thai** รองรับภาษาไทยอ่านง่าย คมชัดทุกขนาดหน้าจอ
2. **ภาพพื้นหลังและพระวจนะหนุนใจ:**
   - ภาพพระเยซูคริสต์ทรงยื่นพระหัตถ์ช่วยคนแบกภาระหนักขึ้นจากหน้าผา พร้อมเลเยอร์ถนอมสายตาให้อ่านตัวหนังสือได้ชัดเจน 100%
   - ข้อพระคัมภีร์: *« บรรดาผู้ทำงานเหน็ดเหนื่อยและแบกภาระหนักจงมาหาเรา และเราจะให้ท่านทั้งหลายหายเหนื่อยเป็นสุข » มัทธิว 11:28 KJV*
3. **ระบบรับชมวิดีโอในเว็บไซต์ทันที (Interactive Video Theater):**
   - คลิกการ์ดวิดีโอเพื่อเปิดรับชมผ่าน Modal Pop-up ได้ทันทีโดยไม่ต้องเปลี่ยนหน้า
   - มีปุ่มเลื่อนดูคลิปก่อนหน้า-ถัดไป และปุ่มแชร์ไปยัง Social Media
4. **หมวดหมู่คำพยาน 3 หมวด (รวม 24 คลิป):**
   - 💼 **การอวยพรธุรกิจ, การเงิน, การงาน, ชีวิตส่วนตัว (11 คลิป)**
   - ❤️‍🩹 **พระเจ้าเข้ามาช่วยกู้และเปลี่ยนแปลงชีวิต (7 คลิป)**
   - 🕊️ **การรักษาจากพระเจ้า (6 คลิป)**
5. **ระบบค้นหาคำพยานแบบเรียลไทม์ (Live Search):**
   - ค้นหาคำสำคัญ เช่น มะเร็ง, ธุรกิจ, กาแฟ, หนี้สิน, ยาเสพติด, ชื่อพยาน
